All 20 files are 1600 × 1000 JPEG placeholders (16:10). Replace them in `public/projects/` using the exact filenames below. Mobile views should be centered on a 16:10 canvas. Do not add a browser frame; the card component supplies it. Update alt text in `data/projects.ts` to describe your replacement images.

Each prompt is also stored beside its image path in `data/projects.ts`. These are fictional concept projects, not client work.
